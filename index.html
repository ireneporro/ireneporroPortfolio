Product standards

Quality is designed into the product.

A few checks I return to while designing product screens, systems and handoff for teams that need clarity at scale.

Interface QA

Before a screen feels finished, I check what users and engineers will actually touch.

  • Hierarchy is visible without explanation.
  • Empty, loading and error states are designed.
  • Components behave consistently across flows.
  • Handoff notes remove implementation guesswork.
Pattern check

Repeated flows reuse decisions.

Patterns should reduce ambiguity, not reinvent the interface screen by screen.

Handoff note

States define quality.

Hover, focus, disabled, validation and edge cases are part of the product, not polish at the end.
